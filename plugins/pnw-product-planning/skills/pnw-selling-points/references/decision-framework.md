# 消费者购买决策框架

本文消费者购买理由、销售型表达对应团队的“买点”。产品特征/优势作为产品卖点，按“SPU × 人群 × 买点”讨论其顾客意义；产品事实及既有SKU差异仍须核对。此用语对应由用户于2026-10-12明确，不能据此宣称鹿比的完整原定义已读取或所有需求已验证。

## 卖点起点与信息主次

用户于2026-09-23确认：卖点架构由用户主导讨论，AI补充。选品或Brief阶段应提出产品主卖点；已有用户判断优先作为研究与延伸的起点。

1. **用户/团队提出方向**：读取选品理由、Brief主卖点及当前意见，保留原始意图。主观产品判断不自动等于消费者需求或效果已验证。
2. **AI收集市场参考**：对线上同款/相似款，研究他方主打什么、怎样表达、有什么证明，补充讨论依据。按market-reference核验来源；他方说法不能作为本品事实背书，也不因出现频繁就取代用户主线。
3. **AI查漏补缺并结合业务判断**：用素材、商品数据库和已有资料补充遗漏亮点、发现承诺缺口；结合当前业务目的、商品定位与经营概况说明补充建议的理由，不凭图片自行重定产品方向。
4. **延伸到消费者端**：围绕讨论后的主卖点，展开购买理由、顾虑回应、信任证据及逐页图文。先读取页面约束，但不按图数反推或拼凑主卖点。

主线缺失时先查已有选品/Brief记录；仍无明确依据，提出少量带来源的候选用于讨论，标明AI补充判断，继续可独立完成的研究，不假装主线已由用户提出。发现主线与事实不符时具体指出冲突，提出收窄或调整建议，不盲从也不静默替换。

在原商品主档简要区分“用户/Brief原始主张、外部参考、AI补充、讨论后采用方向”，不新增填写表或逐页审批。当前明确意见优先于历史Brief；保留变化依据。既有已确认项目不因方法更新自动重写。

## 输入

核对产品身份、真实可售组成与SKU差异、样品/实物/规格证据、用户资料、已有Brief、页面职责与显示容量。用户咨询、评价、售后、搜索或经营结果存在时优先读取去标识资料；缺失则把需求作为假设，不捏造反馈。

每页形成：

`特定消费者与时刻 → 想得到的结果/尚未解决的疑问 → 影响她选择的条件 → 本商品的作用与证据 → 可见图文 → 下一步判断或行动`

消费者“不确定是否值得买/是否适合/选哪个”可以是需要解决的问题；审美与情绪可以直接构成购买动机，不必先造负面焦虑。

## 可用维度（按页面取舍，不是必填分类）

- 想拥有的结果：穿上后希望呈现什么，商品在其中贡献什么。
- 场景适合：在何种裙装、动作或使用条件下发挥作用；不能从产品名称虚构场景。
- 选择理由/差异：相比她实际考虑的方案，具体哪一点值得选；未核实竞品时不宣称独有、更好。
- 可信度：近看结构、材质或使用方式是否支持承诺；不以“高级、精致”替代证明。
- 适配和顾虑：尺寸、颜色、固定方式、数量、适用限制等是否影响购买；只引用真实数据。
- 价值与选择：选哪个SKU、需要哪些组成、是否重复购买；有当前真实价格与适用授权才讲价差优惠。
- 行动条件：看完后是否有足够信息选择、加购或下单；缺关键事实先补齐，不用催单掩盖缺口。

视频的差异型、情绪型、场景型切入用来寻找消费者在意的理由，不作为效果证明，不限定每个商品只能有三条。既有材料是证据来源；围绕用户/Brief主线，结合消费者决策与业务目的讨论维度和优先级，页面意图负责组织表达。

## 消费者端表达的两个核心（2026-09-24用户明确）

用户提出页面停留时间短的业务背景：文案需简洁明了以减少理解和反应时间，并转化成与顾客相关的销售性表达，分清主次。不据此编造具体停留秒数或转化提升。

- **快速看懂**：使用顾客熟悉的具体词语，一次集中表达一个主要意思；减少抽象修饰、绕句和需要猜解的比喻。简洁以能快速理解为标准，不机械追求最少字数；商品对象、关键差异、适用条件不能因缩句而丢失。
- **与顾客相关**：围绕用户/Brief主卖点，说明它与顾客的穿搭结果、审美愿望、实际顾虑或选款有什么关系。不能停在材料名和商家自评，也不能靠加“你”、夸张承诺或催单制造销售感；消费者收益仍受本品证据约束。
- **主次分明**：整组以已讨论的核心购买理由为主线，其他内容支持或补充。单页主标题突出该页最重要的选择理由或答案；支持句补具体特征和理由；细节图、标签或必要正文承接证明与条件，不换词重复标题。层级按页面意图取舍，纯规格和无文案页不强套营销结构。

复核实际图文：第一眼能否理解在说什么；能否明白与自己的需求有什么关系；能否找到支持主张的具体依据。此为编辑检查，不冒充实际顾客测试。完整内部分析继续保留，消费者端按层级压缩；不把全部FABE推理塞上图片。

## 卖点深化为销售型表达

2026-10-05用户明确：结合skill调研与用户提供的卖点进行深化；任务、场景、情绪、对话和身份等方法是销售型表达的深化方向。学习输出要回到具体商品，不能停在方法名称或独立情绪句。

以用户/Brief的原始卖点为主线，将实际市场研究、商品事实与业务定位接入：先说明调研对该主线补充了什么（消费者选择线索、他方表达、顾虑或证明方式），再判断该特征对目标顾客有什么意义，形成可见购买理由与可信依据。市场主张与实际顾客反馈分别标明，不把他方文案作为本品事实或已验证需求。

具体深化在原页面表达包中完成，可合并呈现：

`用户原始卖点 → 本次调研补充及本品依据 → 顾客为何在意 → 销售型主标题/支持句 → 对应画面证明`

每条实际交付应给出具体表达，而非只建议“增加场景感/情绪价值”。任务、场景、情绪、自然对话、审美身份按该卖点选择；不要求五种都用，不以套写法重新决定主卖点。事实锚点应能在标题、支持句或清楚画面中直接识别；文案的销售性来自商品价值与顾客关联，不能只靠形容词、口号或催单。

质感等审美卖点可回应顾客偏好，但具体理由应落到本品可见材料外观、结构或已有可靠资料；精确工艺、性能和优于竞品的结论仍需各自来源。已确认事实支持的卖点直接深化；尚缺依据的具体承诺收窄，继续其他表达，不另设全项目等待；进入正式视觉策划仍须完成 [买点确认](buying-point-confirmation.md) 和原飞轮A→B条件。未确认时继续买点研究，不以可独立写一句文案为由跳过该项目确认。

验收深化结果：保留原始主线吗；调研实际贡献明确吗；顾客关联具体吗；表达简洁且主次分明吗；画面和资料支持其含义吗。无新增资料时如实复用有日期的既有研究，不声称新调研已完成。

## 筛选与整组检查

每条理由检查：与目标消费者相关吗？有本商品的具体作用吗？能用文字/画面说明吗？能帮助解决该页疑问吗？证据支持到哪里？

主线保证整组一致，支持内容按页展开。若两页都只是“搭配更完整”的同义句而无新增证据、选择或场景，重新分工。可解释地关联加购/下单目标，但没有实际数据就不能宣称能提升转化；点击、加购、付款和售后分别观察，整体结果不证明每句文案独立有效。


## FABE与画面证据

来源：用户提供的“卖点可视化的核心公式——说了就要证明”截图及本次学习讨论；用户要求固化的是经辨析的方法，不是截图例子中的全部因果推论或效果承诺。

从消费者任务出发，同步形成 F（可核实的特征）→ A（这项特征为何值得选择）→ B（消费者想得到的结果）→ E（支持对应主张的画面及其事实来源）。A不必是优于竞品，也可以是符合个人偏好；不能仅凭F就认定A、B成立。纯规格、固定品牌和无文案页面按其职责处理，不为套公式编造利益。

### 逐项判断画面能支持什么

- **外观事实**：数量、形状、装饰排列、正反结构，用对应SKU实物全貌/近景支持。局部画面只支持看得见的部分；参考文件名、文案标签不能代替核对实际画面。
- **审美与场景展示**：整体风格、搭配位置、轮廓，用完整穿搭、中景与必要细节帮助消费者判断喜好。主观“甜酷”等可以表达，不把审美偏好说成普遍效果；平铺不能直接证明上身结果。
- **功能、适配与性能**：防滑、舒适、耐用、尺寸适用范围等，需对应真实测量、使用记录或测试条件。出现某场景、模特穿着、五金特写都不自动证明这些利益；无有效依据就收窄、改写或暂不使用该主张。
- **资料型事实**：成分、尺寸、内含等可由可靠记录/标签/测量支持，再设计清晰可读的图文呈现。不能因没有现成照片而否认资料证据，也不能用拍到一张标签替代核实标签内容和SKU归属。
- **生成图**：可承接经事实约束的造型提案与视觉表达，不能作为证明真实功能、材质、适配、耐久或实际使用结果的新增证据。生成得像，不等于实物验证。

在原页面表达包内简要记录“主张 → 来源与支持范围 → 对应镜头/素材 → 缺口与处理”，可用一句或紧凑表格，不另建台账。至少区分：已有事实证据、仍需穿搭展示、仍需实际验证；这些状态可以同时存在于一页的不同主张。

素材已有时绑定实际路径与SKU；只有镜头想法时写“计划/待补”，不能写成已证明。若已有来源而缺展示素材，可继续策划；若来源本身不足，不靠生图补证据。制作前按受影响范围补素材、收窄承诺或保留候选，不阻断其余页面，不增加逐页人工审批。

### 回看案例：皮带扣袜套

- “每只两道心形扣饰”：实物近景与全貌能支持。
- “爱心的甜，皮带扣的酷”：特写支持设计元素，穿搭展示承接整体审美；消费者自行判断是否喜欢，不宣称转化已验证。
- “下摆放宽，穿搭多一层轮廓”：平铺支持前半句，后半句需上身展示，不能将整句都标为已有画面支持。
- “有孔眼，所以可调腿围/不滑落”：推论不成立，需核对真实结构与使用证据，不能以扣饰照片或生成穿搭替代。

交付前双向检查：文案提出的事实/利益是否超出证据；实际画面是否清楚呈现对应部位、数量、搭配关系或条件。漂亮但无关的画面不能承担证据职责；一张图片也不必证明全部卖点。
