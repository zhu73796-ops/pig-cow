# 当前电脑的资料路径

读取当前用户主目录下 `.config/pnw-skills/paths.json`。通过系统获取主目录，不沿用 Jeff 的用户名。缺失时说明缺口，按本次已提供的真实资料继续可独立完成的部分，不猜挂载路径。

- `business_root`：实际共享的 pinkandwhite / Obsidian 业务根目录，须含 `01_系统设计` 等原相对目录。确认 vault 身份和目标笔记后才写入。
- `assets_root`：实际电商视觉资产库根目录，用于来源案例和图片。
- `skills_root`：已安装视觉控制器及 Profile 的技能目录；这两个 skill 不自动安装视觉技能。

正文中的 `{键名}/相对路径` 须以配置值替换后访问。配置必须指向当前电脑真实可读的绝对目录，不创建同名空数据库。

开始受影响任务时检查对应路径。产品身份、生效 AJ、SKU 等事实必须读取本次真实资料；包内规则和市场案例快照不能替代。视觉规则未交付时可列页面草案，不能把历史数量标成当前已批准合同。Obsidian 不可访问时报告未保存。

用户明确提供本次有效资料路径时可使用并说明覆盖范围；不自动把配置指向别的 vault。
